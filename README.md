# gym-log

식사 칼로리와 운동을 기록하는 개인용 웹앱. 아이폰 사파리에서 **홈 화면에 추가**하면
앱처럼 쓸 수 있다.

부위별로 마지막에 어디를 자극했는지 보여줘서 다음 운동 타깃을 정하는 게 핵심이다.
예를 들어 가슴 상부를 최근에 했으면 중앙·하부가 비어 있는 게 한눈에 보인다.

## 개인정보

- **기록은 기기를 벗어나지 않는다.** 서버도 계정도 분석 도구도 없다.
  식사·운동 데이터는 브라우저 `localStorage` 에만 저장된다.
- 이 저장소에 올라가는 건 코드뿐이다. 기록은 올라가지 않는다.
- Content-Security-Policy 로 외부 통신을 브라우저 수준에서 차단해 뒀다.

브라우저 데이터를 지우면 기록도 사라진다. **설정 › 기록 내보내기**로 가끔 백업할 것.

## 직접 돌려보기

```sh
./serve.sh   # http://127.0.0.1:8080
```

서비스 워커(오프라인 캐시)는 HTTPS 에서만 등록되므로, 실제 동작 확인은 배포된 주소에서 한다.
